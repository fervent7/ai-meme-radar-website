## Shared foundation implemented in review source

research_passport.py is a pure local projection over existing journal-shaped
records, not a new hosted endpoint or attestation issuer. Versioned schema
radar-research-passport-preview-v1 preserves chain/token/pool, original provider
origin/reference/block/hash or Solana slot/time, explicit unknowns and finite
expiry. It handles revocation inputs, wrong scope, future time, invalid/boolean
chain points, ambiguous records and mismatched source blocks fail closed. Source
URL keys/userinfo/paths are withheld. Authentication, source trust, revocation
registry, cryptographic signatures and independent RPC corroboration are NOT
implemented by this preview. Producer VERIFIED is only a stored assertion.
All outputs retain signed_attestation=false, security_clearance=false and
transaction_authorized=false. No fee field can buy a favourable assessment.

A byte-identical synthetic fixture generated by actual backend code drives the
website's interactive Living Token Passport preview. Current, expired, revoked
and missing examples use an explicitly controlled example clock, never fetch-time
restamping. Genuine production records are not claimed. Existing research/history
API authentication/rules remain unchanged. This local model is not public API
service readiness or independent security verification.
